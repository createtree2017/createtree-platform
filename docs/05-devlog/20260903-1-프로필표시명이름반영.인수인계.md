# 2026-09-03 프로필 표시명 이름 반영 인수인계

## 작업 개요

계정 설정에서 변경한 이름이 프로필 화면 상단에 반영되지 않는 문제를 수정했다.

## 연결된 PDCA 문서

- 없음: 단일 파일 Quick Fix로 Plan/Design 생략

## 변경 파일

- `client/src/pages/profile.tsx`

## 핵심 변경 내용

- 프로필 화면 상단 표시명을 `user.username` 직접 표시에서 `user.fullName` 우선 표시로 변경했다.
- `fullName`이 비어 있거나 공백만 있는 경우 기존처럼 `username`을 fallback으로 표시한다.

## 변경 이유

계정 설정의 이름 필드는 `/api/auth/profile`을 통해 `users.full_name`에 저장된다. 그러나 프로필 화면은 대표 이름 위치에서 `username`만 표시하고 있어 사용자가 이름을 바꿔도 화면에는 기존 사용자명/닉네임이 계속 보였다. 저장 API와 표시 UI의 기준 필드를 맞추기 위해 `fullName`을 우선 사용하도록 변경했다.

## 동작 확인 상태

- `npm run check -- --pretty false`: 통과
- `git diff --check`: 통과
- `npm run build`: 통과

## 주의사항 / 알려진 이슈

- 브라우저 자동 검증은 사용자 메시지에 `!!테스트!!`가 없어 프로젝트 규칙상 수행하지 않았다.
- 운영 반영 후에는 새 번들 배포가 필요하다. 현재 운영 번들은 기존처럼 `username`을 표시하는 코드가 포함되어 있었다.
- 후속 `!!푸시!!` 요청에 따라 이번 수정 파일만 선별 stage 후 커밋/푸시 대상으로 포함했다.

## 연관 파일

- `client/src/pages/account-settings.tsx`: 계정 설정 이름 입력 및 `/api/auth/profile` 저장 호출
- `server/routes/public-routes.ts`: `/api/auth/profile`에서 `users.full_name` 업데이트
- `server/routes/auth.ts`: `/api/auth/me` 응답에 `fullName` 포함
