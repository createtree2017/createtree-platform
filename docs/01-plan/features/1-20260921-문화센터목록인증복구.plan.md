## 운영 범위

DB 스키마 변경, 세션 저장소 이전, 운영 배포는 포함하지 않는다. 기존 6시간 JWT/14일 갱신 토큰 기간을 사용한다. 유효한 서버 세션은 기존 유지 기간을 따른다. 기존 사용자의 세션과 갱신 토큰이 모두 없으면 재로그인이 필요할 수 있다. `!!푸시!!` 없는 커밋/푸시는 하지 않는다.

## 검증 범위

코드 회귀 테스트, 전체 타입 검사, 프론트/서버 빌드 및 환경 검증을 수행한다. 실제 모바일 브라우저/운영 배포 검증은 별도이며 코드 검증 통과와 구분한다.

## 순차 무결성 재검증 (2026-09-21 후속 요청)

완료: 변경 코드 경계 조건 재검토, 실패 테스트 추가 후 수정, 실제 세션 프로토콜/조회 수명주기 테스트, 전체 타입·빌드·환경 순차 검사. 브라우저는 사용자 요청에 따라 실행하지 않는다. 운영 DB/외부 메시지 발송 스크립트는 무분별하게 실행하지 않는다.
