# 회원 전용 문의 관리 계획

## 목적과 확정 범위

사용자 요청으로 승인된 최소 개발: MY에서 제목·내용으로 비공개 문의를 접수하고, 운영 관리자 대메뉴에서 조회·답변한다. 문의당 답변 1개를 수정할 수 있다. 비회원·첨부·추가 댓글·푸시/이메일·사용자 수정/삭제는 제외한다.

## 후속 범위: 미확인 답변 뱃지

사용자 요청에 따라 MY 문의사항에 미확인 답변 숫자 뱃지와 안내를 추가한다. 목록에도 미확인 답변을 표시하고 상세에서 실제 답변을 표시한 후 읽음 처리한다. DB에 답변 버전/확인 버전 2개 숫자 필드를 추가하여 기기 간 동기화 및 답변 수정/동시 읽기 경계를 보장한다. 메일·푸시는 추가하지 않는다. API/DB/사용자 화면과 코드 테스트를 함께 갱신한다.

| 상태 | 우선순위 | 항목 | 대상 | 검증 기준 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 완료 | P0 | 미확인 답변 뱃지 | DB·API·MY·상세 | 답변/수정 후 증가, 읽은 버전만 차감, 타인 차단 | 기존 답변은 미확인으로 초기화 |

## 검증 원칙

실제 Express 요청과 격리된 DB fixture로 검증한다. 운영 회원/문의 데이터를 테스트 데이터로 변경하지 않는다. 테스트 통과를 무결점 보장으로 표현하지 않으며 발견 결함·해결·미검증 범위를 보고한다.
